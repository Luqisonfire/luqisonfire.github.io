# luqisonfire.github.io

Site pessoal de Lucas Corrêa (luqisonfire): sobre, stack e contato.

HTML e CSS puros, sem build. O tema segue o sistema (claro ou escuro) com os tokens da marca luqisonfire.

## Estrutura

```
index.html          página única
404.html            página de erro
assets/site.css     estilos (tokens da marca no :root)
assets/fonts/       Alata e JetBrains Mono (woff2, auto-hospedadas)
assets/img/         foto
cv/                 currículo em PDF
favicon.svg, favicon-32.png, apple-touch-icon.png, og.png
```

## Publicar

1. Crie o repositório público `luqisonfire.github.io` na conta `luqisonfire`.
2. Envie estes arquivos para a branch `main`.
3. Em Settings › Pages, deixe a origem em "Deploy from a branch", `main`, pasta `/ (root)`.
4. O site fica em https://luqisonfire.github.io

## Atualizar o currículo

Substitua `cv/lucas-correa-curriculo.pdf` mantendo o mesmo nome.
